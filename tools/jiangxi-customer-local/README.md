# 江西客户测算盈亏判断 · 浏览器离线版 1.1

## 直接使用

1. 下载发布包，解压后用最新版 **Chrome 或 Edge** 打开 `江西客户测算盈亏判断.html`。仓库里的成品是 [`dist/index.html`](dist/index.html)，下载原文件后打开，不能在 GitHub 源码预览页里运行。
2. 等待“本地计算器已就绪”，一次选择多个 **PDF账单 / XLS / XLSX用电曲线**。程序自动按企业户号和用电月份归档、去重并核对分次结算。
3. 选择联动套餐，修改 **联动比例、服务费**。页面随即重算，显示各月售电收入、采购成本、赚亏和观察期合计；点“明细”可查看原件、来源页码/行号、分时单价和计算过程。
4. “导出本次测算”下载CSV；“打印报告”可由浏览器另存PDF。点“备份本机资料”保存完整资料，另一台电脑打开同一工具后“恢复备份”即可合并。备份包含客户原件，应像原账单一样保管。

不需要安装Python、运行启动脚本、登录、服务器或域名。约28MiB的单文件中已包含读取和计算组件，**首次打开也可以断网使用**。Mac和Windows使用同一文件；本次实机验收是macOS Chrome，尚未做Windows实机验收。建议优先使用Chrome/Edge，Safari未验收。

资料保存在当前浏览器的本地存储，刷新后可以继续；不同电脑、浏览器或文件位置可能使用不同存储空间。清理浏览器资料、隐私模式、磁盘限制都可能影响保存，重要批次请下载备份。不会自动把资料共享给另一台电脑。新下载的成品不含任何客户资料。

## 当前测算口径

- 价格包为 **2026年12个月、每日48个半小时的月度均价模板**，单位元/兆瓦时，有版本、原表SHA256和单元格来源。跨年、缺价或异常月份会阻断，不跨年套价。9月深谷12:00—14:00已补入；2月同钟点仅春节法定节假日深谷电量另行分配，普通日期保持原平段。
- **原模板预设**：售电价＝(参考价＋服务费)×(1－联动比例)＋实时价×联动比例。服务费仅作用于非联动部分，100%联动时不生效。
- **规则联动预设**：售电价＝参考价×(1－联动比例)＋实时价×联动比例＋全电量浮动费。该预设按已有本地规则资料实现，未随软件发行提供原政策文件，不代表已验证未来年度的正式合同资格；应结合适用规则和合同确认。
- **采购价沿用测算表假设**：80%滚撮＋20%现货。7、8月现货用日前，其余月份用实时。这是当前方案的采购假设，不能当成售电公司实际采购账本。
- 服务费输入单位 **厘/度**，数值等于元/兆瓦时。金额＝千瓦时×元/兆瓦时÷1000；采用Decimal十进制计算。原模板月收入、成本分别四舍五入到分，再相减；规则预设售电价先保留元/兆瓦时三位小数、逐时收入到分后汇总。合计为已纳入月份金额求和。
- 只有账单时，按尖峰/峰/平/谷/深谷电量在对应时段均摊，是**账单拟合**；上传已确认格式的真实曲线后，同户同月优先按真实48点分布计算，不重复叠加账单电量。曲线单位MWh，时段1为00:00—00:30；转千瓦时一次，不再乘0.5。
- 曲线按计量点逐日核查，缺天、冲突版本、总量不平会标记；完整日历月要求适用于本次已确认的平台导出格式。新平台或变更单位应先验证格式，不凭文件名猜单位。
- 只计算收入减采购成本的**情景电量毛差**。调平、偏差考核、佣金、返还、税费及合同附加条款未全部配置；缺少最终月结电量时不把调平费视为已确认的零。未覆盖全年不外推全年，历史毛差为正也不保证未来持续赚钱。

## PDF精度与边界

沿用原工具的pypdf与pdfplumber双通道：对带文字层的已确认江西国网账单提取字段，按字符方向过滤斜向水印后独立核对，检查分时合计与计量点计费电量。保留原始字节、SHA256、原文、页码和核对状态；缺失不补零，冲突不猜数，异常月份不混入合计。

扫描PDF、加密文件、未知地区或新版式会提示核对/拒绝自动采用。本版没有用OCR猜读小数点，不能承诺支持任意水印和版式。当前样本通过双通道核对不代表所有未来文件均可自动核准。

## 开发与更新

此目录独立于仓库根目录的浙江研究站点，不改变其运行入口、部署配置或冻结结果。

用户仅需HTML；以下命令只供维护者重建：

```sh
python fetch_assets.py  # 构建时联网下载依赖，并核验固定SHA256
python build.py         # 从本目录源码构建dist/index.html与指纹清单
```

依赖已随源码提供，完整下载目录后可直接运行 `python build.py`。构建脚本使用Python标准库，不依赖相邻项目或个人目录。修改页面在 `source/web/`，算法在 `python/`，本地存储和下载适配在 `adapter.js`，运行线程在 `worker.js`。原件不写进成品；`bridge.py`连接原算法与浏览器虚拟文件系统。

更新价格时，修改 `python/prices/template_2026.json`，同步调整年份、版本、单位、时段映射和原表来源指纹后重新构建并回归。不同年份应新建对应价格包并扩展显式选择逻辑，不能仅把2026改为新年份沿用旧价格。不要把真实客户原件、备份或测试截图提交到公开仓库。

匿名回归：安装 `openpyxl==3.1.5` 和Node的 `playwright`，准备Chrome后：

```sh
python tests/make_fixture.py /tmp/jx-demo.xlsx
node tests/smoke.cjs /tmp/jx-demo.xlsx
```

默认使用本机Chrome，可通过 `BROWSER_CHANNEL=msedge` 切换Edge，`PLAYWRIGHT_MODULE`指定Playwright模块路径。测试生成虚构企业数据，不需要真实账单。真实账单的私有验收仅公开汇总证据，见 [`ACCEPTANCE.md`](ACCEPTANCE.md)。

第三方依赖版本、下载源及校验值在 `dependencies.lock.json`；许可见 [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md)、`PYODIDE-LICENSE` 和 `licenses/`。

## 1.1 调价与拖拽

新版默认规则联动，全电量计服务费。历史保存的明确套餐仍随原记录保留。

页面大拖拽区可一次接收多个PDF/XLS/XLSX，也可点击选择。微信附件须已下载、且微信向浏览器提供实际文件；只拖到文字或链接会提示先下载。Mac/Windows微信原生拖拽尚未实机验收，浏览器文件拖入已自动化验证。

点击“调整价格”，选月份，在48行表格里修改参考／固定价、滚撮购电价、日前、实时价格，单位元/兆瓦时。展开批量设置，可按起止钟点设置、粘贴Excel矩形区域或复制本月价格到指定月份。修改后“应用并重算”，也可另存为方案。表格原价始终保留，手动价标记为测算方案，不认证实际买入成交。仅修改指定月份；跨客户可选用同一方案。

采购比例和日前／实时选择在采购方案中修改，不与客户联动比例混用。保存的价格、名称、来源文件指纹及套餐参数随完整备份迁移。普通CSV包含价格版本，完整核对记录包含自定义价格快照。修改前后毛差使用相同套餐参数对比，默认基准为内置原模板价格。

价格Excel支持原“联动类”模板（公式需已有计算缓存），或明确的长表：月份、时段、参考价、滚撮价、日前价、实时价。月份为2026-MM，时段为1—48，每月48行。时段1=00:00—00:30，四列价格为元/兆瓦时。未成交挂单、卖出报价不会自动认定为买入成本；不识别的成交导出格式会要求先核对，不能凭文件名猜测。

曲线支持多月、多工作表和分组合计行，冲突与缺月仍标记。账单新增购电费用名称识别，但新市场化/零售版式还需实单验证；多个不同费用口径同时出现时不自动相加。

新版验证：`python tests/test_prices.py`；`node tests/prices.cjs /tmp/jx-demo.xlsx`。后者覆盖文件拖入、默认套餐、定量调价、空值阻断、基准比较、刷新与跨浏览器备份恢复。

## 1.1.1 定比分摊识别修复

部分账单会在主计量点“加减”列扣出本期定比电量，再计入明确关联的子计量点。这种负数属于本期内部转出。新版只有在上级关系、定比量、两个读取通道和全账单总量一致时，才将其识别为内部转移，保留原负数及核对依据。子计量点变损、线损另行核对，不把带损计费量全部当成转入量，也不把子计量点重复加到本期总电量上。

修正旧版将部分定比分摊误认为前期扣减而阻断月份的问题。真正的前期扣减仍要求对应前期账单；未匹配或金额不平仍阻断。

更新时建议先在旧版下载“备份本机资料”，再用新版恢复。若沿用原浏览器存储，启动时会自动重核受影响原件；恢复旧备份或再次上传重复原件也会重核旧错误，不清空客户与价格方案。识别更新可能需要等待；原PDF须存在于备份或本机存档中。迁移记录随完整核对记录保留。

回归测试：`python tests/test_allocations.py`，包括无损和带损内部转移、父电能表编号换行、相邻分析数字、不匹配金额、第二通道不符及真正前期扣减合并。

## 1.1.2 分时占比
账单核对表增加尖峰、峰、平、谷、深谷占比，按各类账单电量除以当月账单总电量计算，显示两位小数；缺失不补零。实际曲线与账单并存时，展示可用账单的分时结构并标明账单口径，仍按账单总电量计算占比。无可用账单结构时显示—。本次未增加或改变价格复制粘贴功能。

1.1.3：谷段和深谷段占比独立展示，分别使用蓝色、紫色背景及加粗大字；尖峰、峰、平占比保留。仅改变显示样式，计算和价格粘贴不变。

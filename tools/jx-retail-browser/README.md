# 江西零售申报助手：浏览器本地计算版

下载 `index.html` 后用 Chrome 或 Edge 打开。Mac、Windows使用同一个文件，不安装Python、Codex、Docker，不购买服务器或域名。首次打开解压运行组件需要几秒钟，文件约17MB。

程序、Python/WebAssembly运行时、依赖包均已嵌入HTML；准备和计算阶段均不需要网络。选择业务表格不等于向服务器上传。程序没有远端计算API、账号系统、遥测或分析脚本；内容安全策略禁止网络连接。

## 使用

1. 等待显示“本地计算器已就绪”。
2. 同时选入价格定义、当月申报表（含套餐）、全月曲线和计量点月电量。也可分次补齐。
3. 点“识别并保存到当前批次”，再点“计算并生成申报表”。
4. 如果存在大电量差异、缺日、缺价格或未知套餐，相关客户保留待核对，结果标为草稿。
5. 同类文件有多个版本时，先明确选择本次采用的文件。换月请先“新建批次”。
6. 下载结果。关闭或刷新页面会清空当前批次，不会自动云端同步给其他人；请保存原表和结果。

当月申报表N/O不参与计算；仅回填计算结果。旧生成表中已知格式的“逐户核对”页会重新生成，不作为规则、价格或修正依据。不同月份不会混合，同字节文件去重。仅含驳回计量点的申报表也可使用：客户均价仍按其全部计量点电量计算，再回填指定名单。

电量大差错不能无依据当普通调平。优先采用电网修正曲线；确有本月本户依据时，方可登记已核对正差比例投影或逾期调平例外。负差、零曲线、逐日取舍不自动推定。修正记录绑定当前资料版本，不跨月继承。网站下载不代表交易中心确认；仍由交易员核对并申报。

## 源码与构建

`index.template.html.in`为不可直接运行的界面模板，`index.template.html`仅作为旧入口跳转，`worker.js`为隔离计算线程，`dist/python/`为Python业务代码，`runtime/`为Pyodide 0.29.0，`dist/vendor/wheels/`为固定版本纯Python依赖。`python build.py`生成`dist/index.html`。直接使用时请打开打包后的成品，不要打开`.in`模板。

计算器复用原Python Decimal引擎，未转写JavaScript浮点公式。导出使用XlsxWriter；之后再读取生成XLSX核对目标数据和模板字段。适用当前已验证的江西套餐口径，不自动解释新政策。PDF仅支持已验证的打印分页表格，不进行OCR猜测。

真实资料验收由私有测试环境运行，不把客户原表、结果、名单、曲线、套餐、密码或历史答案提交到仓库。仓库只发布汇总验收记录。历史回归不是未见数据盲测；Windows实机验收另列状态，不把Mac Chrome测试写成已在Windows测试。

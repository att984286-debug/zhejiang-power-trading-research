# 交互式测算：用新条件现场算，不改旧研究

选择案例，再进入沙盒。页面里的默认电价、资产和电量都是公开手工研究输入，不是私有历史数据预填。

## 储能：电量有限，如何把机会留给后续时段

快速填当前剩余电量比例、剩余充放额度与未来各时段的价格判断，确认标准电池假设后点击“计算剩余时段策略”。先看现在充、放或等待，再看电量轨迹、后续安排与三个办法的差额。

高级可以改容量、功率、充放效率、安全上下限、结束时留电目标、额度来源、模拟损耗和时间间隔。快速转高级继承当前条件；高级转快速不符合预设时先确认，不会静默改掉条件继续显示旧答案。

1次吞吐额度是充入与放出累计达到额定容量的两倍；200兆瓦时电池的0.6次额度为240兆瓦时累计充放电量。并不认证电池寿命。每兆瓦时损耗按双向电网侧吞吐计，效率另进入电量平衡。

现在满放强制第一个完整时段满功率，其余时段再优化；留到指定时间在此之前不充不放，其后再优化。三方案共用相同开始／结束电量与预算，不能通过耗光库存制造收益提升。

价格错误压力入口把原动作固定后重新估价；另点击新预测优化得到的是新计划，不是原计划抵御错误的收益。没有自动执行、实时行情、交易权限或真实调度。

## 发电：先比较锁价，再控制更多业务假设

快速填预计月净上网电量、少发范围、已有承诺、新合同电能量价格及三档现货价格。系统比较新增五档覆盖和可选手填候选。候选百分比作用于研究中可新增承诺的电量，页面同时给出实际兆瓦时与全部预测量占比。

快速明确假设不计机制差价、使用同价代理、已有合同价按新合同价研究、环境价值与其他费用未评价。不是把真实未知资格自动填零。真实问题涉及机制、价格基差或不同已有合同价格时，进入高级控制。

高级可以声明机制比例／预计量及年度额度、资产卖电参考价与合同计费参考价、机制参考价、固定已有合同、履约限制等。全部发电量先参与市场，机制只另计合资格差价；少发和价格变化不重签原合同。未知机制可以保留诊断，但不能给出虚假的完整排名。

“更稳”只指列出的有限联合情况下最低测算金额更高，不是稳赚或统计置信结论。最低金额为正时不是“最大亏损”，所有已算分项仍不是企业完整利润。

## 结果、下载与运行边界

- 修改条件会隐藏旧结果与下载，主动重算后才生成新的输入指纹与运行编号。仍在浏览器编辑框而未提交的修改可能未到服务器，结果始终绑定最近一次已提交快照。
- 默认下载为中文工作簿；技术折叠区可下载同一输入／结果的原精度JSON。用户明确提交的价格和电量可进入本次下载，原购买资料仍不可下载。
- 服务端只使用会话内状态，不把访客条件持久保存到文件、数据库或共享结果缓存。托管平台可能有基础访问日志；不宣称平台完全零日志或企业级隐私保障。
- 最多96个均匀时段，同一交易日剩余窗口；15／30／60分钟正确进入兆瓦到兆瓦时换算。缺失／重复／非法值不补零。
- 储能单次求解限5秒、整次请求限20秒、每个服务进程最多2个并发储能计算，繁忙时立即说明；发电是有限候选与至多九个联合情景的枚举。不保证生产SLA，也不提供抗恶意访问系统。
- 失败、不可行、未知和真实零分别呈现，不复用旧答案、不显示栈或私人路径。平台冷启动、休眠和网络限制可能造成等待；面试前先打开检查。

现场讲法：您改电量和电价，我先看方向，再现场算几个公平可比的方案，解释模型为何充、放、等；发电则看锁价与少发、涨跌的取舍。不把工具输出称为真实交易业绩。
